# Polonez Kapitan

**Elektryczny terenowy wariant Poloneza**  
Open-source • Maintainability First • Circular DIY • Low-Cost

## Wizja

Terenowa, podwyższona, mocniejsza ewolucja platformy Poloneza.  
Zaprojektowana z myślą o trudniejszym terenie, większym prześwicie, wyższym momencie i większej odporności.

Dwa główne warianty:
- **Kapitan Cywilny** – terenowy / wyprawowy / użytkowy
- **Kapitan Wojskowy** – wersja użytkowa o charakterze wojskowym (transport, łączność, lekki patrol, wsparcie logistyczne)

## Zasady projektowe

1. Maintainability First – modularność, łatwy serwis, kasety baterii, power pack
2. Circular DIY + Low-Cost – maksymalny upcycling, druk 3D, spawanie, reuse
3. Metal tylko tam, gdzie są duże siły i bezpieczeństwo
4. Open documentation
5. Wariant wojskowy nie jest „uzbrojeniem” – to platforma użytkowa o zwiększonej odporności i uniwersalności

## Wstępne założenia techniczne

- Napęd: elektryczny, preferowany RWD lub 4x4 (mosty + ewentualnie reduktor)
- Prześwit: wyraźnie wyższy niż klasyczny Polonez
- Zawieszenie: wzmocnione, dłuższy skok, możliwość blokad mostów
- Bateria: system kasetowy (łatwa wymiana / serwis)
- Nadwozie: wzmocnione, proste panele, łatwe do naprawy w terenie
- Wariant wojskowy: dodatkowe mocowania, maskowanie, odporność na trudniejsze warunki, możliwość montażu sprzętu łączności / transportowego
