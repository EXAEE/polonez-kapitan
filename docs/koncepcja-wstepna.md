# Polonez Kapitan – koncepcja wstępna

## Cel
Elektryczny Polonez o charakterze terenowym. Wyższy prześwit, wzmocnione podwozie, większy moment, odporność na trudniejsze warunki.

## Warianty

### Kapitan Cywilny
- Wyprawowy / użytkowy / lekki off-road
- Możliwość montażu bagażników, wyciągarki, dodatkowego oświetlenia
- Komfort wystarczający do codziennej jazdy + weekendów

### Kapitan Wojskowy (użytkowy)
- Platforma transportowa / łącznościowa / logistyczna
- Zwiększona odporność (zabezpieczenia, łatwiejsza naprawa w terenie)
- Mocowania uniwersalne pod sprzęt
- Maskowanie / malowanie taktyczne (opcjonalne)
- Bez uzbrojenia – wyłącznie platforma

## Kluczowe różnice względem Błyskawicy
- Wyższe zawieszenie i prześwit
- Wzmocnione mosty / półosie / wahacze
- Możliwość 4x4 (opcjonalnie)
- Osłony podwozia
- Inna geometria nadwozia (krótsze zwisy, inne kąty natarcia)
- Większy nacisk na serwisowalność w warunkach polowych
